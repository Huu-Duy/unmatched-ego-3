# Unmatched Ego 2 - Local Edition

Game bóng đá 3v3 WebGL chạy trên máy tính cá nhân.

## Hướng dẫn cài đặt và chơi cho bạn bè:

1. **Yêu cầu:** Máy tính cần có cài đặt [Node.js](https://nodejs.org/) (phiên bản bất kỳ từ 18 trở lên).
2. **Khởi động game:**
   - Click đúp vào file `start_game.bat`.
   - Trình duyệt sẽ tự động mở lên tại địa chỉ: `http://localhost:8080`.
3. **Chơi Online:**
   - Vào game, chọn chế độ chơi trực tuyến / ghép trận để cùng chơi với bạn bè.
